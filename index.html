Desarrollo Web

HTML, CSS y JavaScript: El lenguaje de marcado permite estructurar el contenido web, mientras que CSS se encarga del diseño visual y JavaScript añade interactividad y funcionalidad.

HTML (HyperText Markup Language)

Es el lenguaje de marcado estándar para la creación de páginas web. Define la estructura básica y el contenido mediante etiquetas y elementos.

CSS (Cascading Style Sheets)

Es el lenguaje de estilos utilizado para describir la presentación de un documento HTML. Permite definir colores, fuentes, tamaños y layouts.

JavaScript (Programming Language)

Es un lenguaje de programación que permite crear contenido dinámico, controlar la multimedia y animar imágenes en el navegador.

Tecnologías de la web y sus roles

marcas web

Estructura

Construye la base del sitio. Define encabezados, párrafos, listas y enlaces para organizar la información de forma ordenada y accesible.

Estilo

Aplica diseño visual a los elementos web. Controla colores, tipografías, espacios y alineación para una experiencia atractiva.

Interactividad

Añade comportamiento dinámico a la página web, respondiendo a las acciones del usuario como clics, desplazamientos y formularios.
